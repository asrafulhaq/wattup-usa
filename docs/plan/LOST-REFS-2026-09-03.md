# Branches lost to the 2026-09-03 object-store wipe

On 2026-09-03 the local `.git/objects` store was emptied while refs, reflogs and
the index survived. Recovery came from `origin`, which held `main` at
`2d773abb`. 79 of 81 local branches were restored, all of them ancestors of
`main`.

These two were not. Their commits existed only locally, `origin` and `ashraf`
never had them, and their worktree directories under `.claude/worktrees/` were
already gone, so nothing was recoverable:

| Branch               | Tip                                        |
| -------------------- | ------------------------------------------ |
| `feat/csp-nonce`     | `adf40e54a611b18b13b8b012e137d3c7ffc6c105` |
| `test/csp-signed-in` | `9dcf7ecca1d085a2944006d4417184cf53780c09` |

Both were work in progress on finding **F11** (migrate GTM and the
admin-injected script fields to a CSP nonce, then drop `script-src
'unsafe-inline'`). `docs/plan/CHECKLIST.md` still shows B.1 and B.2 unticked,
so nothing recorded as done was lost, and F11 remains open work.

The refs themselves were deleted on 2026-09-03 because they pointed at objects
that no longer exist: `git for-each-ref` exited `fatal` on them, which broke
`git fetch` and made VS Code's Source Control panel report zero changes.
